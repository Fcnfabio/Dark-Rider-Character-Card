# Dark Rider - Character Card

Interactive character card with 3D tilt effects and dynamic lighting. Built with HTML, CSS, and optimized JavaScript.

## Description

Dark Rider is a responsive character sheet card featuring smooth 3D animations and hover effects. The card responds to mouse movement with realistic tilt and shine effects, creating an immersive experience for RPG character displays.

## Features

- 3D card tilt effect following cursor position
- Dynamic radial gradient shine effect
- Smooth transitions and animations
- Fully responsive design
- Dark theme with red accent colors
- Custom Orbitron font integration

## Technologies

- HTML5
- CSS3 (Custom styles, gradients, shadows, 3D transforms)
- JavaScript (Basic, AI-optimized for performance)

## Project Structure
├── index.html

## Installation

1. Clone the repository
2. Open index.html in a modern web browser
3. No build process or dependencies required

## Usage

Hover over the card to activate the 3D tilt and shine effects.
