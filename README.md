# Dark Rider - Ficha de Personaje

Tarjeta de personaje interactiva con efectos de inclinación 3D e iluminación dinámica. Construido con HTML, CSS y JavaScript optimizado.

## Descripción

Dark Rider es una ficha de personaje responsiva con animaciones 3D suaves y efectos hover. La tarjeta responde al movimiento del mouse con efectos de inclinación y brillo realistas, creando una experiencia inmersiva para mostrar personajes de RPG.

## Características

- Efecto de inclinación 3D siguiendo la posición del cursor
- Efecto de brillo con gradiente radial dinámico
- Transiciones y animaciones suaves
- Diseño completamente responsivo
- Tema oscuro con colores de acento rojos
- Integración de fuente personalizada Orbitron

## Tecnologías

- HTML5
- CSS3 (Estilos personalizados, gradientes, sombras, transformaciones 3D)
- JavaScript (Básico, optimizado con IA para mejor rendimiento)

## Estructura del Proyecto
├── index.html
├── styles.css
├── script.js
└── README(es).md


## Instalación

1. Clona el repositorio
2. Abre index.html en un navegador web moderno
3. No requiere proceso de construcción ni dependencias

## Uso

Pasa el cursor sobre la tarjeta para activar los efectos de inclinación 3D y brillo.
